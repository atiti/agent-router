# Support

AgentRoute is alpha software that patches a pinned open-source Codex release. Before asking for
help, update to the latest AgentRoute release and run:

```sh
agentroute doctor
agentroute desktop status
codex --version
```

Search existing issues before opening a new one. For a reproducible bug, use the bug-report form
and include sanitized diagnostics, platform, installation method, and exact reproduction steps.

Do not post API keys, account identifiers, private prompts, transcripts, customer data, or complete
configuration files. Report security vulnerabilities privately through GitHub Security Advisories.

Community support is best-effort. There is no guaranteed response time, compatibility promise for
unreleased Codex versions, or support for unofficial binary modifications.
